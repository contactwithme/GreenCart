# GreenCart 🛒🌱

GreenCart is a full‑stack MERN e‑commerce application focused on a clean shopping experience with user authentication, cart management, orders, and admin/seller features.

## Tech Stack
- **Frontend:** React (Vite), Context API
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Authentication:** JWT
- **Other:** Axios, bcrypt, dotenv

## Project Structure
```
greencart/
│
├── client/        # React frontend
│   ├── src/
│   ├── public/
│   └── .env
│
├── server/        # Express backend
│   ├── models/
│   ├── routes/
│   ├── server.js
│   └── .env
```

## Features
- User registration & login
- JWT‑based authentication
- Product listing & details
- Add to cart & checkout
- Order management
- Address management
- Seller/Admin APIs
